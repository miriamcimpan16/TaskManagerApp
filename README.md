# WPF Task Manager

A simple and practical desktop task manager application built with WPF (.NET 8) that helps you organize your projects and daily tasks efficiently.

## Core Features
- **Add & Delete:** Easily create new projects and tasks or remove them instantly using the delete buttons (`✕`).
- **Persistent Data Storage:** All your projects, tasks, check states, and custom titles are automatically saved to a local JSON file in your user application data folder, ensuring nothing is ever lost.
- **Dynamic Renaming:** Edit project and task titles easily with intuitive double-click and focus triggers.

## How to Run & Use
1. Clone or download this repository to your local machine.
2. Open the project folder in Visual Studio or Visual Studio Code.
3. Build and run the solution using the .NET CLI: dotnet run
